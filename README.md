# Cinema-salesperson-s-workplace

Предметна область: **робоче місце касира кінотеатру**.

## Лабораторна робота №3 — обробка винятків

Програма формує чек кінотеатру (фільм, зал, кількість квитків, ціна, знижка, 3D-доплата) і ділить суму між відвідувачами.

### Що реалізовано
**Рівень 1**
- `InputMismatchException` — некоректне введення чисел (повторний запит у `readInt` / `readDouble`);
- `ArithmeticException` — цілочисельне ділення на 0 при поділі рахунку на 0 людей;
- `finally` — гарантоване закриття `Scanner` та підсумкове повідомлення.

**Рівень 2**
- `InvalidTicketDataException extends Exception` (checked): конструктор `(String message, String fieldName, double invalidValue)` та додаткові поля `fieldName`, `invalidValue`;
- кидається через `throw new` у методі `validate(...)` при порушенні правил: кількість квитків > 0, ціна > 0, знижка 0–100 %, кількість людей ≥ 0;
- перехоплюється окремими `catch`-блоками з виведенням назви поля та некоректного значення.

### Запуск (Java 25, файли в одній папці)
```bash
java lr3cinema.java
```
Дробові числа вводяться через крапку (наприклад, `150.5`). 3D-сеанс: `так` / `ні`.

### Перевірка
| Ввід | Результат |
|------|-----------|
| зал: `abc` | повідомлення, повторний запит |
| кількість квитків: `0` | `InvalidTicketDataException`, дані вводяться знову |
| ціна: `-10` | `InvalidTicketDataException` |
| знижка: `150` | `InvalidTicketDataException` |
| кількість людей: `0` | `ArithmeticException`, повідомлення |
| кількість людей: `-2` | `InvalidTicketDataException` |
